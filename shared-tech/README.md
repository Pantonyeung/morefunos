## Purpose
This directory stores reusable technical systems and engineering standards that can be used by more than one port. These files are not progress logs and are not port business authority.

A technical document belongs here only when the mechanism is reusable across SMT, SMM, Admin or Customer.

## Reading rule
1. Start with the port's own Authority and Engineering Log.
2. If no solution is found, read the MoreFunOS Integrated Engineering Log.
3. If the issue is a reusable technical mechanism, read the relevant Shared Tech document.

## Current shared technologies
- `ADAPTIVE_SYSTEM.md` — responsive/adaptive layout architecture shared across ports.

## File rule
Each technical subject keeps one current file. New findings are appended or integrated into that same file. Do not create V2/Final/Latest parallel technical files. Technical progress and incidents stay in the relevant port or integrated Engineering Log; only stable reusable knowledge is promoted here.
